# Blokky — ресурс-пак

Здесь лежит только готовый ресурс-пак сервера Blokky. Игра скачивает его сама при входе на сервер.

| Файл | SHA-1 | Для |
|---|---|---|
| `blokky-pack-v1.zip` | `e3ba55c4c467d7d51f4f2b935b4702edc92f1e22` | Minecraft 1.21+ |

Прямая ссылка для `resource-pack.url`:
`https://raw.githubusercontent.com/FliXSG/blokky-pack/main/blokky-pack-v1.zip`

Исходник пака (генератор `build.py`) — в закрытом репозитории проекта. Новую версию кладём **новым
файлом** (`blokky-pack-v2.zip`), старый не перезаписываем: у игроков пак кэшируется по ссылке и sha1.
